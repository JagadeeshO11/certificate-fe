# Codeathon 2K26 Frontend

React + Vite frontend for the certificate mail dashboard.

## Environment

Create a `.env` file:

```powershell
VITE_API_BASE_URL_LOCAL=http://localhost:5000
VITE_API_BASE_URL_VERCEL=https://certificate-be-ochre.vercel.app
VITE_DEFAULT_BACKEND=vercel
```

You can switch between both backends from the dashboard UI while developing.

## Run

```powershell
npm install
npm run dev
```

The app runs on `http://localhost:5173` for local development.
